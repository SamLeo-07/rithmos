# RITHMOS — WHERE BANDS RISE

> A cinematic, interactive 2.5D scroll-driven storytelling landing page experience for **RITHMOS**, a live-band competition born in Hyderabad.

---

## The Vision
Rather than a conventional website with stacked sections or a slideshow, RITHMOS is engineered as **ONE CONTINUOUS CAMERA JOURNEY** through a virtual 3D concert and rehearsal world using 2.5D depth layers, procedural glowing audio waveforms, volumetric stage lighting, floating embers, and real-time synthesized rock audio.

### The 5-Section Narrative Arc
1. **Section 1 — The Stage**: Inside the crowd pit $\to$ camera ascends as foreground hands separate $\to$ performers emerge with the vocalist as focal point $\to$ red waveform appears above the stage.
2. **Section 2 — Where Stories Begin**: Arena trusses and lighting dissolve into ember particles $\to$ camera dollies backward and down into an intimate, raw rehearsal room with acoustic grid walls and studio cables.
3. **Section 3 — The Journey**: Spaces evolve continuously (`REHEARSAL` $\to$ `SMALL ROOM` $\to$ `CLUB` $\to$ `LOCAL STAGE` $\to$ `BIGGER STAGE`) with kinetic verbs (`PLAY`, `LEARN`, `PERFORM`, `GROW`) toward the illuminated stage portal.
4. **Section 4 — The Stage Climax**: Camera breaks through the illuminated doorway into a colossal concert arena with kinetic 3D typography (`EVERY`, `STORY`, `NEEDS`, `A`, `STAGE.`) weaving through depth layers.
5. **Section 5 — Where Bands Rise**: Stage lights converge, particles vortex inward, waveform locks onto the logo crest, and the authentic RITHMOS logo resolves cleanly with band registration and roadmap CTAs.

---

## Tech Stack
- **Three.js (WebGL)**: Virtual 3D camera spline, calibrated 2.5D depth planes, procedural shaders, and point cloud particle field.
- **Lenis**: Silky-smooth inertia scroll interpolation.
- **Web Audio API**: Real-time synthesized rock soundscape (48Hz sub-bass, crowd ambience, electric guitar feedback) with scroll-reactive filter modulation.
- **Vite**: Modern build tooling and HMR dev server.

## Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm

### Installation
```bash
# Clone the repository
git clone <your-repo-url>
cd Rithomos

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
